# 台股開盤前趨勢評分器 V2

這是可部署到 GitHub Pages 的公開版本，同時呈現兩套獨立模型：

- 第一版「均線技術分析」：以5／10／20日線、支撐、市場同步、期貨、信用交易及費半條件進行階梯式評分。
- 第二版「TSMOM時間序列動能分析」：以多期間連續動能、資料可信度與風險閘門決定分數及部位上限。

桌面版依序顯示雙模型評分與總結、均線技術分析細項、TSMOM細項，以及市場K線圖。最上方另有「外資上市買賣超 × 新台幣」同步訊號：外資與新台幣趨勢同步向上為黃金交叉，同步向下為死亡交叉；一升一降則顯示方向分歧。

兩個總分欄位會從每日快照尋找證交所的前一交易日，並顯示該日分數作為比較；沒有該日快照時顯示 `N/A`。

同步方向以共同資料日的 5 日／20 日均值判定。外資 5 日平均買賣超高於 20 日平均代表向上；USD/TWD 5 日均值低於 20 日均值代表新台幣走強。此訊號目前只作交叉確認，不額外加入兩套模型分數，避免重複計分。

外資與 USD/TWD 的公布日期可能不同。圖表會讓兩個序列各自延伸到來源的最新資料日，並分別顯示最新日期與數值；黃金／死亡交叉仍只使用雙方都有資料的共同日期。費半圖表也會在圖卡上直接顯示最新交易日、收盤與漲跌幅。

## 資料更新

GitHub Actions 於台北時間每天約 06:00 執行 `python server.py --refresh-only`，更新 `latest_market_data.json` 與每日快照後部署網頁。GitHub 排程可能延遲；頁面會顯示實際資料產生時間與台股資料日。

## 本機使用

執行 `啟動趨勢評分器.cmd`。本機版可即時呼叫 API；GitHub Pages 版則讀取 Actions 產生的最新 JSON。

本工具僅供研究與風險管理，不構成投資建議。
